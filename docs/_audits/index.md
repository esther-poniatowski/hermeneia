# Audits

Records the state of hermeneia at a given date, with the measurements, decisions and planned work derived from that state.

- [Development state of hermeneia](state-assessment.md): orders the work that removes the defects blocking the development of hermeneia
- [Conflicts with the oikos style](oikos-style-conflicts.md): proposes a resolution for each conflict between a hermeneia rule and an oikos rule
- [Alignment with the oikos prose rules](oikos-rule-alignment.md): matches each oikos rule with the hermeneia rules detecting it, as input to the rule specifications
- [Boundary with the geonexus checkers](geonexus-boundary.md): assigns the kinds of finding reported by the geonexus checkers to geonexus or to hermeneia
